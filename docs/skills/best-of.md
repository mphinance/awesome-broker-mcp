# Best-of: agent skills for trading, sorted by the job

**Every trading skill, read line by line, dated, and labeled by whether the guardrail is code or a polite sentence.**

This is the short list. The [scoreboard](README.md) is the exhaustive one (about 370 skills, 37 brokers). This page picks one winner and one runner-up for each job, so you can start from "what do I need the agent to do" instead of "which broker". The broker is a column. The rungs (G0 to G5), Limits and Bypass fields are defined in [ENFORCEMENT.md](ENFORCEMENT.md). Read that first if the column headings below are new.

**30 entries, 15 jobs, a winner and a runner-up each.** Picks are opinion. The evidence is in the linked doc.

## The inclusion gate

A skill is on this page only if all three hold:

1. **Licence.** OSI-licensed, or marked **link-only**. Link-only means the repo has no usable licence file (or the licence only sits in a manifest or per-skill frontmatter), so this repo does not republish the text. You get a summary, a short quote at most, and a link pinned to the commit.
2. **Pinned and read.** A commit SHA is recorded and the skill was read, per the method line of its doc. Skills the doc says were only partly read are not here. The one entry with no commit (eToro's server-served file) is pinned by a SHA-256 of the body instead.
3. **No unflagged hazard.** Anything from that doc's "things to know" list that applies to the entry is in its **Read first** note below. A skill with a hazard nobody flagged does not make the list. Skills that fail this gate are in [Not recommended, with evidence](#not-recommended-with-evidence).

**Verified** is the scrape date recorded in each doc, 2026-11-11. This page was assembled from those docs on 2026-11-12. The upstream repos were not re-opened for it, and nothing was run. A rung here is a read of the design, not a test.

## Not recommended, with evidence
