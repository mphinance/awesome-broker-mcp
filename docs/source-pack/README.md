# Source pack

Machine-generated material from the public
[NotebookLM source pack](https://notebook.google.com/notebook/7764266e-a289-4224-9cca-d0b278f7b7ca)
(created 2026-10-09 from a deep-research run, plus three Robinhood primary pages added by hand).

| File | What it is |
|---|---|
| `sources.md` | Every source in the notebook: title and URL. Full text stays in the notebook. |
| `report.md` | NotebookLM's briefing over those sources. |
| `broker-matrix.csv` | NotebookLM's per-broker table (official MCP, trade, paper default, safety, source). |

**These are leads, not facts.** They are AI-generated, cover about 26 brokers (the directory has 60+),
and are known to conflate things: an aggregator's draft-first flow got attributed to a broker, and
community servers can be marked official. Nothing here overrides a `brokers/*.md` entry. A claim
changes an entry only after a human opens the primary source the pack points to.

The infographic is not stored here (5 MB PNG); it lives in the notebook.
